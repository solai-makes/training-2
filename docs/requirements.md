# 業務要件

## 1. 初期リリースの範囲

初期リリースでは、管理者による商品登録・一覧表示と、購入者による商品検索・在庫確認・注文操作業務要件を提供する。

対象機能:

- 商品コード、商品名、説明、価格、在庫数を登録する。
- 登録済み商品を管理画面で一覧表示する。
- 商品コードまたは商品名で商品を検索する。
- 商品の現在在庫を表示する。
- 注文を作成、参照、確定、キャンセルする。
- 注文確定時に在庫を引き当て、確定済み注文のキャンセル時に在庫を戻す。

対象外:

- 決済、配送、クーポン、商品画像。
- 商品の編集・削除、返品、注文の分割。
- ゲスト注文と複数通貨。

## 2. 商品と在庫

- 商品コードは必須の文字列で、前後空白を除去した値を大文字・小文字を区別して一意にする。
- 商品名は必須で、前後空白を除去する。空文字は許可しない。
- 説明は任意の文字列とする。
- 価格は日本円の税込金額を1円単位の整数で保持する。0円以上、上限は9,999,999円とする。
- 在庫数と注文数量は0以上の整数とする。在庫登録時は0を許可し、注文数量は1以上とする。
- 商品登録時の在庫数は初期在庫であり、注文作成では減らさない。
- 在庫は確定処理と同じトランザクションで更新し、負数を許可しない。

## 3. 商品検索

- 商品コードは完全一致、商品名は部分一致（大文字・小文字を区別しない）で検索する。
- 商品コードと商品名を同時に指定した場合はAND条件とする。
- 条件未指定の検索は全商品を対象とする。
- 商品コード昇順、同一コードは商品ID昇順で並べる。
- ページングは`page`（1以上）と`pageSize`（1〜100、既定20）を使う。
- 結果がない場合は空配列と総件数0を返す。

## 4. 注文状態と在庫

注文状態は`draft`、`confirmed`、`cancelled`の3種類とする。

```text
draft ──確定──> confirmed ──キャンセル──> cancelled
  └────────キャンセル──────────────> cancelled
```

- `draft`の作成時は在庫を変更しない。
- `draft`の確定時に、明細の数量を在庫から減らす。全明細を減らせない場合は注文状態も在庫も変更しない。
- `draft`のキャンセルでは在庫を変更しない。
- `confirmed`のキャンセルでは、確定時に引き当てた数量を一度だけ戻す。
- `cancelled`からの再確定・再キャンセルは禁止する。
- `confirmed`からの再確定は禁止する。

## 5. 注文明細と金額

- 1注文に1件以上の明細を含める。
- 同一商品を複数明細に分けることは許可せず、API入力で拒否する。
- 注文作成時に商品コード、数量、保存時点の単価を明細へコピーする。
- 注文合計はサーバーが保存済み単価×数量で計算する。クライアントから合計金額を受け取らない。
- 商品が削除・変更されても、既存注文の明細単価は変わらない。

## 6. 再送と競合

- 注文作成は`Idempotency-Key`を必須とし、同一利用者・同一キーの再送では最初の注文結果を返す。異なる内容で同じキーを使った場合は409を返す。
- 確定の再送は、すでに`confirmed`なら同じ注文状態を返し、在庫を再度減らさない。
- キャンセルの再送は、すでに`cancelled`なら同じ注文状態を返し、在庫を再度戻さない。
- 確定とキャンセルが競合した場合は、先にロックを取得して状態遷移を確定できた操作だけを成功させ、後続操作は現在状態に応じて409を返す。
- 同じ在庫を複数注文が確定する場合は、行ロックを取得してから在庫を確認する。在庫1に対する同時確定は成功1件、失敗1件、最終在庫0とする。成功者は固定しない。

## 7. 権限と認証

- 管理者は商品登録・商品一覧を利用できる。
- 購入者は商品検索・在庫表示・自分の注文の作成・参照・確定・キャンセルを利用できる。
- 注文の所有者は認証トークンのsubjectで識別する。
- 管理操作と注文操作は認証必須とする。未認証は401、認証済みでも権限不足は403を返す。
- 他人の注文の存在を推測できないよう、参照・操作は404として扱う。

## 8. エラー方針

共通エラー形式は`{ code, message, requestId }`とする。内部情報、SQL、スタックトレースはレスポンスに含めない。

| 状況 | HTTP | code例 |
| --- | ---: | --- |
| 入力不正 | 400 | `VALIDATION_ERROR` |
| 未認証 | 401 | `UNAUTHENTICATED` |
| 権限不足 | 403 | `FORBIDDEN` |
| 注文が見つからない、所有者不一致 | 404 | `ORDER_NOT_FOUND` |
| 状態競合、重複キー | 409 | `CONFLICT` |
| 在庫不足 | 409 | `INSUFFICIENT_STOCK` |
| 想定外のサーバー障害 | 500 | `INTERNAL_ERROR` |
